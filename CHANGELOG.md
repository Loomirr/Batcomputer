# Changelog

## 0.9.0-beta.1 — 2026-08-18

First public beta candidate.

- Native multi-suit mod authoring for LOTDK Expanded.
- Playable and cutscene visual donors with gameplay-donor separation.
- Part grafting, donor-backed material generation, face workflows, texture cooking, equipment,
  glider, and supported animation authoring.
- Custom static-mesh OBJ import with socket-aware preview and bake workflow.
- Native PawnTag, DCMD, UIMD, StringTable, gameplay-tag configuration, and Asset Registry output.
- Release validation, direct test installation, and player-ready ZIP generation.
- Embedded 3D viewer, base-game Red Brick colour preview for compatible characters, and mod-scoped
  author notebook.
- Guided first-run setup, one-click character extraction, responsive dialogs, and copyable
  diagnostics.

### Beta limits

- Windows x64 and the current supported game build only.
- LOTDK Expanded is required to run generated suit mods.
- A matching `.usmap` and a local Unreal Engine 5.6 installation are required for complete author
  builds.
- Red Brick creation is not part of this beta; the viewer only previews shipped colour palettes.
- Custom skeletal-mesh cooking and skeleton transfer are not supported.
- Complex equipment/controller behavior still requires an in-game verification pass.
