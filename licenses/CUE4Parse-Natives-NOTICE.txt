CUE4Parse-Natives.dll
=====================

native/CUE4Parse-Natives.dll is a prebuilt binary from the CUE4Parse project.
Batcomputer uses it for exactly one thing: decompressing ACL-compressed
animation data, which is how LEGO Batman: Legacy of the Dark Knight stores
facial expression poses. CUE4Parse offers no managed ACL decoder, and the
format is not practical to reimplement correctly.

Everything else in the preview pipeline (texture decode, mesh conversion,
pak access) is managed code.

Updating
--------
The DLL must stay ABI-matched to the CUE4Parse PackageReference version in
Batcomputer.csproj (currently 1.2.2.202607). It is not published as a
standalone release asset; it ships inside FModel's single-file executable and
can be lifted out of that bundle without running it.
