# Third-party notices

## retoc-oodle

Batcomputer's portable release includes `Tools\retoc-oodle\retoc.exe`, built from the
[retoc-oodle fork](https://github.com/Loomirr/retoc-oodle) of
[trumank/retoc](https://github.com/trumank/retoc). It uses the MIT License.
The complete license is included in `licenses/retoc-oodle-MIT.txt` in the release.

The helper can load an Oodle runtime from a local Unreal Engine installation you select.
Batcomputer does not bundle or redistribute `oo2core_9_win64.dll`, Unreal Engine files, or game files.

## Other bundled libraries

The release's `licenses` folder contains the notices for the CUE4Parse native helper and three.js.
Keep that folder with Batcomputer when redistributing the tool.
