# Batcomputer 1.0 — first official release

Build suits, create playable characters and customize equipment for LEGO Batman:
Legacy of the Dark Knight using assets from your own game installation.

## What's included

- Suit, character, equipment and animation workflows with editable projects,
  build checks, mod packaging and 3D previews.
- Skeletal preview/bind-pose scale fixes and the Blender rig-preparation helper.
  Skinned imports remain experimental and require a matching native game rig.
- Editable character pawn families, an Import/Export category, improved review
  controls and more accurate settings indicators.
- An animated Update center, visible app version, verified downloads,
  restart-now/install-on-exit, recovery backups and a themed one-time completion
  prompt after successful startup.
- Organized portable files: one top-level EXE with runtime DLLs under `app/`.
  Third-party notices are included; Oodle/game runtimes are not bundled.

## Installation

Extract the entire **Batcomputer-v1.0.0-win-x64.zip** into a new writable folder
and open **Batcomputer.exe**. Do not copy only the executable. A SHA-256 sidecar
is included for verification. Existing projects can be opened from their current
location; back them up before moving between versions.

The updater-compatible **Batcomputer-update-win-x64.zip** contains the same app.
Older builds without the updater require this one manual installation first.
Pre-1.0 releases are legacy/manual-only. Enable beta updates only if you want
future prereleases; stable updates do not require the beta option.

Mod authoring requires the game, matching mappings and configured tools as
described in the included Documentation. Install the LOTDK UE4SS framework
separately for the supported in-game mod workflows.

## Update verification

The live GitHub full-ZIP flow passed download, verification, installation,
runtime startup, rollback and preservation checks. The author confirmed the
in-app restart and completion prompt. Changed-file downloads have local test
coverage; live GitHub incremental acceptance remains a separate follow-up.
Keep the first stable publication full-ZIP-only until that check is complete.

Application-file backups are retained under Updates → Settings & recovery.
The updater does not replace projects, settings or installed game mods.
