# Batcomputer 1.0 — First Official Release

Batcomputer 1.0 is finally here! Huge thanks to everyone who's been testing,
sending over broken mods and helping me track down issues during the betas.

## What's new

- **The updater is here.** Check for updates inside Batcomputer, download them,
  then restart when you're ready. It has the animated 3D Batcomputer, and you can
  easily see which version you're running.
- **Skeletal mesh fixes.** Fixes for meshes missing from the 3D viewer and the
  scale issues that made imported bodies or attachments massive or distorted.
  The Blender rig-preparation script is included in `Tools/SkinnedMesh`.
- **Better character editing.** Change a custom character's pawn-tag family
  without having to remake the character or change its ID and display name.
- **A cleaner workflow.** Import/Export has its own category, the Review menu
  has more useful details and filters, and the Settings indicators actually
  check the paths you've selected.
- **A tidier install.** One main `Batcomputer.exe`, with the DLLs and bundled
  runtime tucked away in `app/`.

All the suit, character, vehicle, equipment and animation tools from the betas
are still here, along with the fixes and improvements made along the way.

## Installing or updating

Download **Batcomputer-v1.0.0-win-x64.zip** and extract the whole ZIP. You can use
a new folder or merge it into your existing Batcomputer folder and replace the
matching files. Close Batcomputer first and back up your projects just in case.
Don't delete your existing folder or copy only the EXE—the `app/` folder is needed.

Your settings and projects aren't included in the download, so a normal merge
keeps them. The **Batcomputer-update-win-x64.zip** is the same app, named for the
updater. Both ZIPs have a `.sha256` file attached.

## A few things to know

- Older versions without the updater need this one manual update first.
- Future betas will stay as prereleases. Leave beta updates off if you only want
  official releases. Pre-1.0 versions are now legacy/manual downloads.
- Skinned FBX imports are still experimental. They need the correct native rig
  and weights; Batcomputer doesn't automatically rig your model.
- Game assets, Oodle and LOTDK UE4SS aren't bundled. Keep using your own game
  files and install the framework separately.

If something breaks, send me your Batcomputer version, what you were doing and
the error or diagnostics so I can look into it.
