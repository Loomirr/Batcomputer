# Batcomputer 1.1.1 Beta 4

This beta fixes the additional animation build blocker found with the supplied custom animation library.

## Animation compatibility

A supported exporter wrapper above the native Root is now accepted only after decoding the clip and verifying its track layout, constant exporter scale and unit-scale named Root. Required body bones, parent relationships and reference transforms must still match. Root-motion, locked-root and additive clips do not receive this exception. Animation bytes and skeleton names are not rewritten.

The reported saved replacement and all six related clips passed validation. The library's 24 clips were inspected; a genuinely different short-character rig remains blocked against the normal-height donor. Regression checks cover both accepted wrappers and unsafe hierarchy/proportion changes. In-game confirmation is still needed: this is compatibility validation, not automatic retargeting.

The animation browser now explains when the selected animation is already assigned. Choosing a different eligible clip still enables replacement.

All earlier beta fixes are included, including queued texture imports and cape, replacer and build improvements. Persistent build caching remains off by default.

## Download and update

Enable **Stable + beta** in Batcomputer's update settings, then check for updates.

- **Batcomputer-update-win-x64.zip** is the complete portable installation, including the Windows x64 .NET runtime. Use it for new installations or manual updates.
- **Batcomputer-update-from-1.1.1-beta.3-win-x64.zip** is the smaller updater package for an unchanged Beta 3 installation. It is not standalone; let the updater apply it.

Other versions or modified installations use the full download automatically. Back up projects before updating. For a manual update, close Batcomputer, extract the full ZIP into a new folder and select your existing workspace.

Existing ImageSharp dependency advisories remain unresolved. No supplied private projects, animation libraries, mod files or extracted game assets are distributed.
