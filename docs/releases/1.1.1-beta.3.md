# Batcomputer 1.1.1 Beta 3

This beta fixes an overly strict animation skeleton check and improves texture importing.

## Animation compatibility

Animation replacements may have extra peripheral helper or attachment bones when all of the donor's required bones, parent relationships and reference transforms match. A larger bone count alone no longer blocks the build.

Missing required bones, changed proportions or parents, malformed extra branches and additive-mode mismatches still block builds. This is compatibility validation, not automatic retargeting. Regression tests cover extended rigs, including the native 53-bone Batman reference pose with a synthetic 79-bone superset. The originally reported custom animation has not been supplied for direct testing and still needs user confirmation in-game.

## Texture imports

- Start another single import while previous textures cook.
- Use batch import to choose names, types and profiles per texture, with thumbnails and multi-selection.
- Press Import to close batch setup and send the jobs to the queue under Your Character.
- Follow progress and cancel or retry jobs in that shared queue. Results stay attached to the suit that started the import.

All earlier Beta 2 fixes are included. Persistent build caching remains off by default.

## Download and update

Enable **Stable + beta** in Batcomputer's update settings, then check for updates.

- **Batcomputer-update-win-x64.zip** is the complete portable installation, including the Windows x64 .NET runtime. Use it for a new install or manual update.
- **Batcomputer-update-from-1.1.1-beta.2-win-x64.zip** is the smaller updater package for an unchanged Beta 2 installation. It is not a standalone installation; let the updater apply it.

Other versions, or installations with changed baseline files, use the full download automatically. Back up projects before updating. For a manual update, close Batcomputer and extract the full ZIP into a new folder, then select your existing workspace.

Existing ImageSharp dependency advisories remain unresolved. No private mod projects or game assets are distributed with this release.
