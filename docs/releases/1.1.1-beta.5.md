# Batcomputer 1.1.1 Beta 5

This beta adds character attribute tuning and a modernized editor. All earlier beta fixes are included, including animation compatibility, queued texture imports, cape and traversal fixes, visual replacers and build improvements.

## Character attributes

Open **Abilities → Character attributes** on a custom character or suit to tune 34 supported values:

- Running, sprinting, jump height, forward glide speed and glide descent rate.
- Ground acceleration, braking, crouch speed and friction.
- Air control, gravity, descending gravity and maximum fall speed.
- Grapple speed, acceleration, damping and drag.
- Glide acceleration, braking, sideways movement and steering.
- Maximum health, defense, attack and critical power, base damage, incoming hit stun and takedown Focus cost.
- Focus capacity and combat/traversal reward power.

The editor groups controls in a category sidebar with enabled counts, readable setting cards and **Reset all**. Every override is optional. Unchecked values retain the character's existing setup, and rebasing can preserve suit-specific tuning or inherit the parent character's attributes.

Builds verify native attribute fields, required active attribute sets and the generated effects. These edits stay local to the character or suit and add no runtime polling. Visual replacers remain visual-only. Persistent build caching remains off by default.

The attribute changes passed save/reopen, clean rebuild/reset, native binding and regression checks. Baseline, combined movement/traversal and health/combat/Focus presets were also confirmed in-game. The extra categories remain experimental across other character loadouts: native upgrades, individual attacks and movement modes can affect results. Power values use native points rather than guaranteed percentages, and capacity changes do not directly refill resources. See the [attribute guide](https://loomirr.github.io/Batcomputer/guides/abilities/#character-attributes).

## Download and update

Enable **Stable + beta** in Batcomputer's update settings, then check for updates.

- **Batcomputer-update-win-x64.zip** is the complete portable installation, including the Windows x64 .NET runtime. Use it for new installations or manual updates.
- **Batcomputer-update-from-1.1.1-beta.4-win-x64.zip** is the smaller updater package for an unchanged Beta 4 installation. It is not standalone; let the updater apply it.

Other versions or modified installations use the full download automatically. Back up projects before updating. For a manual update, close Batcomputer, extract the full ZIP into a new folder and select your existing workspace. Keep `Batcomputer.exe` and its `app/` folder together; no separate .NET installation is needed.

No private mod projects, test packs, settings, supplied animation libraries or extracted game assets are distributed. Existing ImageSharp dependency advisories remain unresolved.
