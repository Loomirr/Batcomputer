# Batcomputer 1.1.1 Beta 1

Small follow-up to stable 1.1.0.

- **Face replacement:** verified native Face-component recipes can be selected again after removing a face. Incomplete recipes, face accessories and unknown donor contexts remain blocked. Use Faces for changing printed materials; use an exact native part recipe to replace the overlay mesh.
- **Readable icon names:** new studio icons use names such as `Classic_Icon_left`, with short numbered revisions instead of GUIDs. Existing textures and assignments are preserved until you generate replacements.
- **Blender icon add-on:** supports the authored four-frame icon template with single/all-slot rendering, transparent PNGs (256px suit tile, 512px portraits), configurable frames and overwrite protection. Preserves template lighting, materials, camera animation and quality settings; restores temporary output settings afterward. Install `Tools/Blender/batcomputer_icon_namer.py` over the old add-on and restart Blender. The third-party template itself is not bundled.
- App-only artwork, web UI and native support now live under `src/Batcomputer` in source; installed app paths are unchanged.

## Updating

Select **Stable + beta**, then check for updates. Stable-only users remain on 1.1.0.

- **New/manual installation:** download `Batcomputer-update-win-x64.zip` and extract the entire archive, keeping `app/` beside the executable. The Windows x64 runtime is included.
- **Existing 1.1.0 installation:** the updater can use `Batcomputer-update-from-1.1.0-win-x64.zip` when reusable files match. Other versions or altered dependencies use the full ZIP automatically. The patch is not a standalone installation.

The face fix has automated regression coverage, but the reported user's exact suit still needs in-game verification. Existing 1.1 limitations, including ImageSharp advisories, remain unchanged. Original 1.0 clients may need a shorter installation path or manual full-ZIP update if restart handoff stalls. Private mod assets and abilities are not included.
