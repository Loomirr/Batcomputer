# Batcomputer 1.0.0-beta.3 — updater prerelease test

This is a beta and the first live GitHub updater test, not a stable release.
Back up editable projects before switching builds.

## Download and installation

Download **Batcomputer-update-win-x64.zip** and extract the **entire** ZIP into a
new folder. Open Batcomputer.exe. There is now one top-level executable; `app/`
contains the required DLLs and bundled .NET runtime. Do not copy only the EXE.
The `.zip.sha256` asset lets you verify the archive with `Get-FileHash`.

Older public builds without an updater need this one manual installation first.
Updater-capable copies can enable beta releases and use Updates → Check →
Download → Restart now. Your settings, projects and installed mods are not
update targets; replaced application files are retained for recovery.

## Highlights

- GitHub update checks, version display, restart-now/install-on-exit, recovery
  backups and a one-time version confirmation after successful startup.
- Animated Batcomputer Update center with an offline 3D model and reduced-motion
  support.
- Organized portable layout and support for verified changed-file updates.
  **This first live test publishes the full ZIP only.** Smaller changed-file
  downloads have local test coverage and will receive a separate GitHub test.
- Skeletal export/preview scale and bind-pose fixes; the reported Minifig08
  body/attachments tests were confirmed working in-game by the author.
- Editable custom-character pawn families, Import/Export category, improved
  review controls and more accurate settings-path indicators.
- Source-pinned ACL/retoc helpers and expanded third-party notices. Oodle is not
  bundled or downloaded: configure your existing local runtime when required.

Pre-1.0 releases are now **Legacy**: available for manual archival downloads,
but never offered or downloaded by the new updater. 1.0 betas remain eligible.

The archive includes `Tools/SkinnedMesh/Batcomputer_PrepareBlenderRig.py`.
See the bundled Documentation and CHANGELOG for details and experimental limits.
