# Batcomputer 1.1 — Beta 1

First beta since 1.0! This one brings together a bunch of work on the 3D viewer,
animation tools, Parts catalog and vehicles, along with fixes for saved projects.
Huge thanks to everyone testing things and sending me the stuff that breaks.

## Characters and the 3D viewer

- **Animation previews.** Browse a character family's animations with the body,
  face and attachments playing together. Characters start in their rest pose,
  so you aren't thrown straight into an idle when opening the viewer.
- **An animation creator.** Move, rotate and scale bones with gizmos placed on
  the selected bone, add and retime keyframes, scrub playback and resize the
  timeline. W moves, R rotates and E scales.
- **Get your animations into a mod.** Cook validated drafts into the animation
  library and assign them to your suit without doing the manual Unreal editor
  workflow. You still need a configured Unreal Engine 5.6 install for cooking.
- **Better materials and faces.** Improved material inheritance, LEGO normals,
  microdetail and face-layer controls. The viewer is still a preview, not a
  perfect recreation of every game shader.
- **Optional suit icons.** The icon studio can render portraits and suit tiles,
  with better edges and a test that doesn't replace your existing icons. You
  don't have to use it to make or build a suit.

## Parts

- **A bigger All parts toybox.** Browse parts together and filter them by their
  attachment point.
- **Less duplication.** Meshes with lots of character references are grouped
  instead of showing up over and over.
- **Clearer attachment choices.** Inspect the native wiring recipes. Inferred
  and preview-only assets are labeled so you can tell what's ready to graft
  and what still needs checking.

## Vehicles

- Choose native boost and sound styles, use twin boost outlets, tune boost
  speed/acceleration and preview flame placement.
- Change the Forever driving base's flame color with private effects, without
  replacing the original car's boost. This can't be combined with the other
  custom boost chains yet.
- Native paint finishes, editable material copies and better defaults for
  decorative lamp meshes.
- Give custom characters a native/custom default vehicle, keep their donor's
  vehicle or choose no default vehicle.
- Older saved vehicle FBXs can be rebuilt with the scale fix while keeping
  materials, settings, old cooks and a recovery copy of the project.

## Fixes

- Saved suits no longer report a generated parent Blueprint as missing just
  because its file path was lost during loading.
- Incomplete cached stages are rebuilt instead of being treated as ready.
- Copying a saved suit with an imported FBX inside its cache folder no longer
  fails because the same file is copied twice.
- The Blender rig-preparation helper now handles native Root and AttachRoot
  rigs properly.

## Installing or updating

Download **Batcomputer-update-win-x64.zip** and extract the whole ZIP. For an
existing install, close Batcomputer first, back up your projects, then merge
the ZIP into that folder and replace the matching files. Don't delete your
existing folder or copy only the EXE—the `app/` folder is needed.

You can also enable **beta releases** in the Update center, then Check for
updates → Download → Restart now. Settings, projects and installed mods stay
where they are. There is just one full ZIP and its `.sha256` checksum for this
release, and that same ZIP works for new users.

**A quick correction from me:** I missed the support needed for the new patch
ZIPs in 1.0, so this update needs the full download. That's on me. This beta
includes that support, so future updates can use smaller patch downloads for
compatible versions. The full ZIP will still be there for new installs or
when a patch can't be used.

## A few things to know

- This is a beta, not a new stable release. Leave beta updates off if you only
  want official releases; 1.0 is still the stable version.
- Animation creation, vehicle effects/audio and custom-character vehicle
  choices are still experimental. Check your rebuilt mod in-game before
  sharing it.
- Game assets, Oodle and LOTDK UE4SS aren't bundled. Keep using your own game
  files and install the framework separately.

If something breaks, send me your Batcomputer version, what you were doing
and the error or diagnostics so I can look into it.
