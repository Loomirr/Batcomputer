# Batcomputer 1.1.1 Beta 2

This prerelease includes the general fixes since Beta 1. Back up editable projects before updating.

- **Capes and native identity:** Joker/Harley suits and cape adapters retain their own idle/combat animations, voices, equipment, abilities and upgrade references. Alternate costume animation inheritance and non-glide traversal rows are preserved. Cape material edits remain supported. Repeated packaging no longer corrupts generated parent-class names.
- **Correct traversal ownership:** suit packages no longer bake in unconditional Joker/Harley glide/grapple grants. Mayhem uses native upgrade requirements. Install **LOTDK UE4SS 0.2.1** separately for Character Freedom's temporary normal-mode support for registered modded suits.
- **Visual replacers:** use the Replacers tab with the existing suit editing tools, add the result to a mod and build normally. Exact-target replacements preserve gameplay, AI and quest identity; they conflict with other mods replacing the same cooked packages. This remains experimental across scenes and missions.
- **Faster, smaller builds:** eligible identical character/vehicle outputs share only when cooked content and dependencies match. Native input, voice and animation work is reused within the build, including indexed voice-media lookup. Suit-specific voices, visuals and gameplay remain independent. Persistent preparation caching is **off by default**; build-local reuse is bounded and temporary.
- **Authoring repairs:** rebasing keeps saved visual edits; suit-local textures and UI icons remain correctly scoped; removed face overlays no longer cause face-animation packaging errors.
- **Normal-map PNG export:** authored BC5 normals reconstruct blue from their stored red/green components. Other channels and packed-mask exports remain unchanged.

## Updating

Enable **Stable + beta**, then check for updates. Stable-only users remain on 1.1.0.

- **New/manual installation:** download `Batcomputer-update-win-x64.zip` and extract the entire archive. Keep `app/` beside `Batcomputer.exe`. The Windows x64 .NET runtime is included.
- **Existing Beta 1 installation:** the updater can use `Batcomputer-update-from-1.1.1-beta.1-win-x64.zip` when reusable files match. Other versions or altered dependencies automatically use the full ZIP. The patch is not a standalone installation.
- Restart the game after rebuilding/installing affected mods. Batcomputer does not install the UE4SS framework as part of its own update.

## Verification and limits

The Joker/Harley cape tests passed in-game with the updated Character Freedom runtime. Offline checks cover 39 native variants, their paired-cape animation graphs, exact native loadout/upgrade preservation, six complete ordinary/cape builds, invalid staged outputs and normal-map exports. Build-sharing changes were also tested with a multi-suit mod while preserving unique content.

These checks do not establish every costume, scene or co-op combination in-game. Private character assets, recipes, test PAKs, extracted content and user settings are not included. Existing ImageSharp dependency advisories remain unresolved. Original 1.0 clients may need a short installation path or the full ZIP if restart handoff stalls.
